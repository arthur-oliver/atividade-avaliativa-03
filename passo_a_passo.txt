1. INICIALIZAR O NODE

Execute:

npm init -y

2. INSTALAR AS BIBLIOTECAS

Execute:

npm install express mysql2 dotenv

3. CRIAR O ARQUIVO .ENV

Na mesma pasta do arquivo atividade_avaliativa_03.js, crie:

.env

Exemplo:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=sua_senha
DB_NAME=db_vendas
DB_PORT=3306
PORT=3000

Se o MySQL não tiver senha:

DB_PASSWORD=

4. INICIAR A API

No terminal:

node atividade_avaliativa_03.js

Se estiver funcionando, aparecerá:

Servidor funcionando na porta 3000

5. TESTAR SE A API ESTÁ FUNCIONANDO

Antes dos outros testes, abra o Thunder Client.

Método:

GET

URL:

http://localhost:3000/

Clique em Send.

Resposta esperada:

{
"mensagem": "API funcionando!"
}

6. ABRIR O THUNDER CLIENT

No Visual Studio Code:

1. Abra a extensão Thunder Client.

2. Clique em New Request.

3. Escolha o método HTTP.

4. Informe a URL.

5. Para POST e PUT, abra Body.

6. Selecione JSON.

7. Informe o JSON.

8. Clique em Send.

12. TESTE - REGISTRAR VENDA E CALCULAR COMISSÃO

Método:

POST

URL:

http://localhost:3000/vendas

Body:

{
"id_venda": 1,
"id_vendedor": 1,
"id_regiao": 1,
"data_venda": "2026-10-09 10:00:00",
"valor_venda": 2000,
"tipo_cliente": "PF"
}

Neste exemplo:

Vendedor = 6%
PF = 2%
Norte = 1%

Total = 9%

Comissão:

2000 x 9 / 100 = 180

A resposta deverá apresentar:

"valor_comissao": 180
